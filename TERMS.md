## 1. Service description

The bot shows Minecraft Java server availability and an aggregate player count. It may display this as Discord activity and through the slash command `/serverstatus`.

The service is provided as-is. There is no promise of continuous uptime, instant updates, or error-free status readings. A reported online/offline state can be wrong if the status check fails, the network is down, or the Minecraft server does not answer the status protocol.
