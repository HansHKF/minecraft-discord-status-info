# Minecraft Discord Status Bot

Minecraft Discord Status Bot is a **private, non-commercial** Discord bot. It shows whether a Minecraft Java server is available and how many players are connected.

The bot updates its Discord activity with an aggregate player count such as `3/20`. Members of the private Discord server can also use `/serverstatus` for a private status reply.

It is not a player list, chat logger, public status website, or official Minecraft or Discord product.
