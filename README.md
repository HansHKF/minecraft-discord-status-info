# Minecraft Discord Status Bot

Minecraft Discord Status Bot shows whether a Minecraft Java server is available and how many players are connected. It is intended for a **private Discord server**.

The bot updates its Discord activity with an aggregate player count such as `3/20`, and it provides the slash command `/serverstatus` for a private status reply.

It is designed to share only aggregated server facts. It is not a player list, chat logger, or public status website.

See [PRIVACY.md](PRIVACY.md) for how status data is handled.
